# 板块 3：Windows 长开机挂机防重启与系统体验补齐

> **定位与范围取舍**：普通人用 Windows 跑 AI，绝大多数电脑显卡并不适合折腾本地大模型，直接调云端大模型更省心省钱——所以本板块**不展开本地模型/显存调优**（真有 8G/16G 显存装 Ollama 嫌慢或爆显存的，只记一句口诀：设好环境变量 `OLLAMA_CONTEXT_LENGTH=8192` 防默认长上下文撑爆显存即可）。本板块只专注解决天天都会撞上的两件刚需：**① 怎么安全长开机 / 过夜挂机不睡眠、不被更新半夜重启；② 怎么用最少现成工具补齐系统体验，顺便用好 Windows 本身反胜 Mac 的原生神技。**

---

## 一、先把两件事用大白话讲透（给人看的）

### 1. 长开机 / 过夜挂机：为什么跑着跑着就断了？怎么稳住？
Mac 跑长任务一句 `caffeinate` 就搞定；Windows 过夜掉线通常栽在 3 个地方：**空闲自动睡眠（或笔记本合盖触发 Modern Standby）**、**Windows Update 半夜偷偷重启**、**笔记本用电池撑不过 5 分钟**。

把这 3 块按下面的安全边界配好，就能做到 80% 场景稳定挂机过夜（不靠野脚本、不破坏系统更新）：

| 挂机拦路虎 | 靠谱做法（安全可逆） | 必须看清的边界与坑 |
|---|---|---|
| **空闲自动睡眠 / 熄屏断活** | **首选微软 `PowerToys Awake`**（等价 Mac `caffeinate`，临时保唤醒、不改系统电源计划，关掉即恢复）；<br>若需要长期当挂机主力，再配合 **`powercfg` 设插电（AC）永不睡眠、但保留 10 分钟自动息屏**。 | `Awake` 只在**当前已登录桌面**时有效，且默认允许显示器按计划息屏省电（只保主机不睡）；挂长任务时千万别用电池，必须插电源。 |
| **Windows Update 半夜自动重启** | **所有版本通用 2 招（最稳）**：<br>① 系统「设置 → Windows 更新 → 高级选项 → 使用时段」拉满到最长 **18 小时**；<br>② 连续几天要跑关键挂机任务前，直接点一下**「暂停更新（最多可暂停 5 周 / 35 天）」**，等任务跑完再恢复。<br>**专业版（Pro）额外可选**：组策略开启「对于有已登录用户的计划自动更新安装，不执行自动重新启动」。 | **家庭版 vs 专业版边界**：家庭版没有组策略编辑器（`gpedit.msc`），网传直接改 `HKLM\...\Policies\WindowsUpdate\AU` 注册表在不少 Win11 家庭版里会被系统忽略；且微软官方明写过了合规最后期限系统仍可能重启。**严禁**用第三方流氓脚本直接禁用 `wuauserv` 更新服务（会把微软商店、WinGet 和安全补丁一起弄废）。 |
| **笔记本合盖挂机 / 塞包里** | **强烈推荐：插电 + 开着盖子平放桌面 + 等 10 分钟自动息屏**（既不睡眠又不闷热）。 | **现代轻薄本（Modern Standby / S0ix）真相**：拔电（DC）合盖时哪怕设了“不采取任何操作”，微软系统机制也最多只保活 **5 分钟** 就会强行冻结桌面程序；就算插电改了 `LIDACTION 0` 合盖不睡，**散热极差还可能烤伤屏幕，严禁合盖塞电脑包！** |

### 2. 系统体验补齐：少装软件，只要最值的几样 + 激活原生神技

不用学网上装一堆美化插件和托盘小工具，**1 个微软官方工具箱 + 1 个可选搜索神器**就够把日常顺手度拉齐到跟 Mac 一档：

#### （1）1 个必装微软官方工具箱：`Microsoft PowerToys`（开源免费，自带签名不踩雷）
装完之后**把不需要的模块全关掉**，只开下面这 **5～6 个最高频功能**（其余全关，不占内存、不乱抢快捷键）：
1. **Awake**：一键让电脑保持清醒（支持无限期、定时几小时、或只保持唤醒允许息屏），过夜挂 AI 任务直接开它。
2. **Command Palette（命令面板，新版替代旧版 Run）**：默认 `Win+Alt+Space`（可自己改成顺手的快捷键），按一下直接搜应用、搜文件、输 `>` 跑命令、切窗口、查剪贴板，对标 Mac 的 Spotlight / Raycast。
3. **Peek（空格预览）**：自 PowerToys 0.95+ 起默认快捷键就是 **`Space`（空格键）**！在资源管理器选中图片、Markdown、代码、文档按一下空格直接预览，**装了它就不用额外再装 `QuickLook` 了**。
4. **Text Extractor（屏幕 OCR 取字）**：默认 `Win+Shift+T`，网页不让复制的字、视频画面里的报错截图，框一下直接变文字进剪贴板（注：需系统已装对应中文/英文 OCR 语言包）。
5. **Always On Top（窗口置顶）**：默认 `Win+Ctrl+T`，把终端或参考文档钉在最前面，对照抄配置不乱跑。
6. **Advanced Paste（含纯文本粘贴）**：`Win+Shift+V` 打开增强粘贴，或 **`Ctrl+Win+Alt+V`** 直接无格式纯文本粘贴，防止网页富文本贴进文档把排版搞乱。

#### （2）1 个高价值轻量补充（按需装，不强求）
- **`Everything`（开源/免费，极轻）**：Windows 原生搜索慢得要命，装上它（`voidtools.Everything`）全盘几百万个文件**毫秒级搜出文件名**，找脚本、找配置文件全靠它。
- *（可选二选一）`QuickLook`（`QL-Win.QuickLook`）*：只有当你觉得 PowerToys 自带的 `Peek` 预览部分格式不够全时，才换用它，**千万别和 Peek 两个同时开着抢空格键**。

#### （3）不用装任何软件！Windows 原生反胜 Mac 的 4 个真香神技
很多人拿 Windows 对标 Mac 时容易忘掉，下面这 4 件事 **Windows 出厂自带就比 Mac 原生还顺手**，直接用起来：
1. **`Win + V` 原生剪贴板历史**：按一下点「打开」即可启用，平时连续复制好几段报错、路径或图片，按 `Win+V` 随时挑着贴进 AI 对话框（Mac 原生没有历史剪贴板，还得装第三方）。
2. **`Win + Shift + S` 截图直进剪贴板**：框选截图完**不往桌面乱堆文件**，直接在微信、Claude、ChatGPT 里按 `Ctrl+V` 就发出去了。
3. **`Win + Z` 原生分屏布局**：鼠标悬停窗口最大化按钮或按 `Win+Z`，秒选两栏/三栏/四宫格，自动记住分屏组（Mac 原生多年一直靠第三方甚至付费软件解决）。
4. **原生按应用调音量 + 外接普通屏字体更锐利**：右键任务栏小喇叭打开「音量合成器」，单独把某个浏览器标签/音乐软件调小声；另外外接常见 1080p/2K 显示器时，Windows 的 ClearType 看长日志和代码通常比 Mac 更锐利不发虚。

#### （4）安全红线内的 AI 提速小提示（别踩雷）
- **千万别关 Windows Defender 杀毒，也别去关「智能应用控制（SAC）」**！
- 如果感觉 AI 扫代码/跑构建（`git status`、大量小文件读写）特别卡，最多只把**你自己放纯代码的固定工作文件夹**（例如 `C:\Projects`）按需加进 Defender 排除项；**绝对不要给整块硬盘、用户目录或 `Downloads` 下载目录加排除**。

## 二、核心交付物：直接复制发给你的 AI 的交办提示词

把下面这段话直接发给你这台 Windows 电脑上的 AI，它会先体检和备份原电源状态，征得你同意后再稳妥调好：

```markdown
请你帮我把这台 Windows 电脑的「长开机/过夜挂机稳态」和「日常顺手度补齐工具」调好。要求安全、可逆、少装重软件，严禁破坏系统更新服务或关闭杀毒软件。

【第 1 步：先体检并记录原配置（只查不改，汇总后等我确认）】
1. 检查我这台电脑的系统版本（Windows 10/11 家庭版还是专业版）：
   `Get-CimInstance Win32_OperatingSystem | Select-Object Caption, Version`
2. 判断这是台式机还是笔记本（是否有电池）：
   `Get-CimInstance Win32_Battery`
3. 读取并记录我当前的活动电源方案及插电（AC）休眠/息屏配置（**把原数值完整抄给我留底，方便以后一键恢复**）：
   - `powercfg /getactivescheme`
   - `powercfg /query`（重点提取 `STANDBYIDLE` 睡眠、`HIBERNATEIDLE` 休眠、`VIDEOIDLE` 息屏的 AC 默认秒数）
4. 检查以下工具是否已安装：`Microsoft.PowerToys`、`voidtools.Everything`（可选 `QL-Win.QuickLook`）。
5. 汇报体检结果，让我确认要装哪些工具、是否允许修改插电电源设置。

【第 2 步：安全配置长开机与过夜防中断（征得我同意后执行）】
1. **调好插电（AC）电源策略（不睡、不休眠、但自动息屏省电）**：
   - 运行（需要改电源时执行）：
     `powercfg /change standby-timeout-ac 0`
     `powercfg /change hibernate-timeout-ac 0`
     `powercfg /change monitor-timeout-ac 10`
   - **不要动用电池（DC）时的休眠策略**，防止平时带出门放包里掉电过热。
   - 如果是笔记本，明确提醒我：**过夜挂机请插电源并开盖平放散热，严禁合盖塞电脑包**（Modern Standby 拔电合盖 5 分钟必冻结程序）；**不要擅自修改合盖动作 `LIDACTION`**，除非我明确要求插电外接显示器合盖用并已知晓散热风险。
2. **Windows Update 防半夜重启（严格按系统版本区分，严禁禁用 `wuauserv` 更新服务）**：
   - 通用引导（所有版本都必须告诉我怎么点）：带我去「设置 → Windows 更新 → 高级选项 → 使用时段」，建议手动调满 **18 小时**；并提醒我跑跨夜长任务前可在更新页点「暂停更新（最长 5 周）」。
   - 如果体检确认是 **专业版 / 企业版（Pro/Enterprise）** 且我要求加策略防重启：指导我在 `gpedit.msc`（计算机配置 → 管理模板 → Windows 组件 → Windows 更新 → 管理最终用户体验）开启「对于有已登录用户的计划自动更新安装，不执行自动重新启动」，或者在征得我明确同意后用管理员权限设置 `HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU` 下的 `AUOptions=4` 与 `NoAutoRebootWithLoggedOnUsers=1`（同时诚实说明：过了合规最后期限系统仍可能重启）。
   - 如果是 **家庭版（Home）**：不要瞎写大概率无效的组策略注册表，老实用「暂停更新 + 18 小时使用时段」。

【第 3 步：安装并精简设置系统体验工具（按我第 1 步选定的执行）】
1. 安装微软官方 **PowerToys**（已装则跳过）：
   `winget install --id Microsoft.PowerToys --source winget --accept-source-agreements --accept-package-agreements`
   - 装完提醒我在 PowerToys 设置里：**只打开需要的高频模块**（`Awake`、`Command Palette`、`Peek`、`Text Extractor`、`Always On Top`、`Advanced Paste`），其他暂时不用的模块全部关掉省资源、防快捷键冲突。
   - 提醒我 `Awake` 在系统托盘里像咖啡杯一样：临时过夜跑任务时点一下设成「无限期保持唤醒 / 保持屏幕关闭」，用完随手关掉即可；并注意 `Awake` 只在已登录桌面时生效。
2. 如我需要全盘秒搜文件，安装 **Everything**：
   `winget install --id voidtools.Everything --source winget --accept-source-agreements --accept-package-agreements`
3. （仅当我嫌 PowerToys `Peek` 不够用时才装，否则跳过防抢空格键）：
   `winget install --id QL-Win.QuickLook --source winget --accept-source-agreements --accept-package-agreements`
4. 提醒我顺手激活 **Windows 原生 4 神技**：按一次 `Win+V` 开启剪贴板历史；常用 `Win+Shift+S` 截图直贴；常用 `Win+Z` 分屏；右键任务栏音量图标用音量合成器。
5. **安全红线**：绝不让我关掉 Defender 或智能应用控制（SAC）。只有当我主动反馈 AI 扫纯代码目录卡顿时，才问我是否只针对我指定的纯代码文件夹（如 `C:\Projects`）加一条 Defender 排除项。

【第 4 步：跑完验收与留存一键恢复清单】
全部配完后请验证并汇报：
1. 跑 `powercfg /query` 核对当前活动方案里 AC（交流电）的睡眠和休眠超时是否已为 `0x00000000`（永不）、显示器息屏为 `10` 分钟；
2. 确认 PowerToys（及选装的 Everything）已可正常启动；
3. 把我原来的电源设置值 + 下面这条回滚命令完整发给我存底：
   - 恢复单条示例：`powercfg /change standby-timeout-ac <原分钟数>`、`powercfg /change hibernate-timeout-ac <原分钟数>`
   - 一键重置回 Windows 默认电源方案：`powercfg -restoredefaultschemes`
```

## 三、出问题自己粘胶水：常见小毛病速查表

| 遇到的毛病 | 真实原因 | 粘胶水修法 |
|---|---|---|
| **笔记本明明设了「合盖不采取任何操作」，合盖跑任务过几分钟还是断了** | 现代轻薄本默认用 Modern Standby（S0ix）：只要**没插电源（DC）**，合盖后系统最多保活 5 分钟就强行冻结桌面进程 | 挂机必须插电；最稳的做法是**开盖平放散热 + 设 10 分钟息屏**，别强行合盖烤屏幕 |
| **开了 `PowerToys Awake`，晚上锁屏或离开后还是停了 / 屏幕黑了** | 正常设计：PowerToys 文档明确写了 `Awake` 锁屏后会允许显示器熄屏（但保持主机醒着）；若电脑彻底休眠，多半是拔电或被电池规则接管了 | 过夜挂机必须插电源；如果需要锁屏后也稳稳跑，直接配合 `powercfg /change standby-timeout-ac 0` |
| **Windows 11 家庭版照着网上改了 `NoAutoRebootWithLoggedOnUsers` 注册表，半夜还是照样重启** | 家庭版不支持组策略，部分更新策略键在家庭版会被忽略；且超过强制截止期时系统也会强行重启 | 别跟家庭版注册表较劲，每次跑多天长任务前去更新设置点一次**「暂停更新（最多 5 周）」+ 拉满 18 小时使用时段**最省心 |
| **按 `Space` 预览文件没反应，或者和 `QuickLook` 打架** | PowerToys 0.95 之前的老版本 `Peek` 默认键是 `Ctrl+Space`；或者同时开了 `Peek` 和 `QuickLook` 抢同一个空格键 | 升级到新版 PowerToys（0.95+ 默认就是 `Space`）；如果已装 `QuickLook`，在 PowerToys 里把 `Peek` 关掉即可二选一 |
| **`PowerToys Text Extractor` 识别不出中文，全是乱码或空** | 机器里缺少对应语言的 Windows 系统 OCR 语言包 | 按提示在 PowerShell 查系统已装 OCR 包，或在「系统设置 → 时间和语言 → 语言和区域」补装中文/英文语言包里的手写/OCR 组件 |
| **`Command Palette` 或 `Always On Top` 快捷键跟输入法/终端冲突** | 比如 `Win+Alt+Space`、`Win+Ctrl+T` 撞了别的软件热键 | 直接在 PowerToys 对应模块设置里改一个不冲突的快捷键，把用不上的模块开关关掉 |
| **电脑半夜没重启，但早上起来发现 Claude / 网页 / IDE 自己退出了** | 很多桌面客户端（如 Claude Desktop、Electron 应用）会在后台自动下载热更新并静默重启自己 | 过夜跑重要自动化任务尽量放**终端 CLI（`pwsh` / Git Bash / 无界面后台进程）**里跑，少依赖会自己静默更新的 GUI 桌面端 |
| **用 `winget install` 安装软件卡住不动或报源证书错误** | 国内网络连微软源或 CDN 波动，或本地 `winget` 源缓存太旧 | 先试 `winget source update`；再不行就直接去官方 GitHub Releases 页面下载安装包双击装，效果一模一样 |
