# 板块 1：让 Windows 操作桌面尽量不抢鼠标（贴近 Mac 无障碍体验）开源方案

> **定位**：不自己造软件、不写重代码。只把目前开源界最顶尖的现成工具串起来，配上一段**直接发给对方 AI 的安装与干活提示词** + **常见小毛病胶水表**。对方 AI 照着装、照着本机情况微调，就能把日常软件操作做到 **70%～80% 不抢鼠标、不打断人干活**。

---

## 一、先对人讲清楚：能做到哪、做不到哪（期望管理）

### ✅ 70%～80% 能做好的场景（日常办公、网页、大多数桌面软件）
只要你的 Windows **已开机登录、没锁屏、目标软件没有被最小化到任务栏**，AI 就可以像 Mac 一样「暗地里干活」：
- **看界面结构**（按钮叫什么、输入框在哪、当前写了什么字）
- **点按钮、勾选复选框、展开菜单、下拉选择、滚动页面**
- **往输入框填字、清空重填**（支持记事本、微信PC版部分控件、Office 局部界面、大多数 Win32/WPF/WinForms/Electron/Chrome 应用）
- **结果**：**你手里的真实鼠标光标纹丝不动，你正在聊微信或写文档的窗口不会被抢走焦点**。

### ❌ 做不到的 20%～30%（别在这些地方白折腾）
1. **游戏、画图软件、视频剪辑时间轴、自绘界面（如部分 Flutter/Canvas）**：软件本身没有向系统暴露按钮信息，必须看截图点真实坐标。
2. **拖拽、鼠标悬停、右键菜单、双击连击**：Windows 底层要求真实鼠标才能触发，后台做不到。
3. **电脑锁屏时 / 跳出管理员权限弹窗（UAC 黑屏提示框）时 / 目标软件是管理员权限打开的**：Windows 安全机制（UIPI）会直接拦掉普通 AI 的指令。
4. **软件被最小化缩进任务栏时**：Windows 会暂停刷新它的界面结构，必须先恢复窗口显示（可以不抢前台恢复，但不能缩着点）。

## 二、选用的现成开源核心工具（不重复造轮子）

这套方案只用市面上现成验证过的三样东西，按优先级配合使用：

1. **浏览器 / 网页类（优先度最高，100% 不抢鼠标）**：直接走浏览器调试接口（Playwright / CDP / OpenCLI），不碰 Windows 桌面鼠标。
2. **首选桌面无障碍工具：`agent-desktop`（Vercel 开源，2.6 万★）**
   - **优点**：会把屏幕上的按钮变成 `@e1`、`@e2` 这样的编号，AI 一看就懂、极省 token；官方自带严格的「后台不抢鼠标模式」，不会偷偷动你鼠标。
   - **唯一门槛**：它的安装文件**没有微软商业签名**，极少数开了「Windows 智能应用控制（SAC）」的新电脑可能会拦；如果被拦，立刻自动切换下面这个微软自家工具。
3. **官方防拦截备选：`winapp ui`（微软官方出品，WinGet 安装）**
   - **优点**：微软官方自带签名，杀毒软件和系统安全策略不会乱拦；`inspect / invoke / set-value / get-value` 全走无障碍后台，不碰鼠标；而且部分动作连锁屏都能跑。
   - **注意**：只有 `invoke / set-value / get-value / scroll --direction` 不抢鼠标；它的 `click / hover / drag / send-keys` 会抢真实鼠标，提示词里已写死禁止乱调。

> 为什么**不用**最火的 `Windows-MCP`（1.19 万★）？核查源码发现它的点击走的是 `SetCursorPos + mouse_event`，**每次必抢真实鼠标**，不符合我们本板块的目标。

## 三、核心交付物：直接复制发给你的 AI 的提示词

把下面这段话直接发给你自己的 AI（Claude Code / Codex / Cursor / OpenCode / Pi 等），它就会自动检查你的电脑、选好装哪一个工具，并记住以后操作电脑的规矩：

```markdown
请你帮我在当前这台 Windows 电脑上配置「不抢鼠标的桌面无障碍控制方案」。记住我们只整合现成开源工具，不自己造轮子。

【第一步：帮我检查并安装最合适的工具（二选一，先试首选）】
1. 先检查我这台电脑是普通用户还是管理员权限终端，确认 Node.js / npm 或 winget 是否可用。
2. 首选安装 `agent-desktop`：
   - 运行 `npm install -g agent-desktop`
   - 运行 `agent-desktop status` 测试能否正常返回。
   - 如果执行时被 Windows SmartScreen / 智能应用控制(SAC) / 杀软拦截，**绝对不要让用户关掉系统安全保护**，立刻放弃它，改用第 3 步的微软官方工具。
3. 官方防拦备选安装微软 `winapp`（WinGet 有官方签名）：
   - 运行 `winget install Microsoft.winappcli --source winget`
   - 装完重启终端或刷新 PATH，运行 `winapp ui --help` 验证可用。
4. 安装完后，立刻用当前屏幕上的「记事本（Notepad）」或一个已打开的普通软件做一次后台无障碍测试：只读界面结构、尝试后台填字或点按钮、再读回文本核对成功，确保过程中**没有移动我的鼠标指针、没有抢走我当前的输入焦点**。

【第二步：把下面的干活铁律写进你的长期记忆 / 项目规则里】
以后我要你帮我操作电脑软件时，必须严格按下面 3 级顺序走：
- L1（零打扰优先）：能用命令行、直接读写文件、或浏览器调试接口（CDP/Playwright）完成的事，绝不去点桌面软件界面。
- L2（后台无障碍操作）：必须点桌面软件时，只许使用无障碍语义动作（不移动鼠标、不夺焦点）：
  * 如果用 `agent-desktop`：只用 `snapshot`、`find`、`get`、`click @ref`、`set-value`、`clear`、`select`、`toggle`、`check`、`expand`、`scroll`、`wait`。**严禁**私自加 `--headed` 参数，严禁私自调用 `mouse-click` / `drag` / `right-click` / `type`。
  * 如果用 `winapp ui`：只用 `inspect`、`search`、`get-property`、`get-value`、`wait-for`、`invoke`、`set-value`、`scroll --direction`。**严禁**私自调用会注入真实键鼠的 `click`、`hover`、`drag`、`send-keys --via send-input`、`screenshot --capture-screen`。
  * **结果必核验**：点完或填完字后，必须再读一次界面内容（`get` / `wait` / `get-value`）确认页面真生效了；写操作如果超时或不确定是否成功，**绝不自动重试**（防止重复提交订单或表单），先读页面再说。
  * **PowerShell 防坑**：在 PowerShell 里调用 `agent-desktop` 带 `@ref` 的编号时，必须给参数加单引号（如 `'@s1:e8'`），否则 PowerShell 会把 `@` 当特殊语法报错。
- L3（做不到就停下来问人）：遇到以下情况必须**立刻停住并汇报**，绝对不许偷偷抢我鼠标：
  * 窗口是最小化状态、电脑锁屏、遇到管理员提权窗口（UIPI 权限拒绝）、或者需要拖拽/右键/画布点击；
  * 汇报给我：「这一步后台无障碍点不到（原因：xxx），需要借用你鼠标 3 秒，或者你手动点一下这一步？」。

【第三步：如果本机报错，你按下面的小修小补表自己粘胶水】
遇到任何问题不要直接放弃，先对照下面排查：
1. 报错窗口最小化 / 元素 `offscreen`：提醒我把窗口恢复显示（不要夺我焦点，可用最小化恢复但不激活的方法，或让我点开），Electron/Chrome 软件刚启动要等几秒才出完整按钮树。
2. 操作 Chrome / Edge / Electron 软件第一次 `set-value` 把窗口弹到了最前面：这是 Chromium 内核特性，先尽量改走浏览器 CDP 接口；如果必须用 UIA，提前告诉我它会弹一次窗口。
3. 填字没触发网页或软件的保存/提交事件：UIA 填值有时不触发键盘监听，先试着查一下附近有没有提交按钮可以 `invoke`，不行再停下来问我是否借用一次前台输入。
4. 中文输入法吃字或填成乱码：只走 `set-value` 整体赋值，绝不用模拟按键逐字敲；确保终端和输出是 UTF-8。
5. 遇到管理员权限启动的软件报 `PERM_DENIED / E_ACCESSDENIED`：这是因为当前 AI 终端权限比目标软件低，告诉我需要重开一个同级权限的终端，或者手动处理该软件。
```
