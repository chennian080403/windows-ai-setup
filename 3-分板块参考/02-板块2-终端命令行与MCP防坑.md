# 板块 2：Windows 终端、命令行与 MCP 丝滑化方案（以现有 PS7 资产升级）

> **定位**：基于 Windows PowerShell 规则沉淀与 Windows Terminal 满血规范，结合实测排查补齐「AI 偷偷跌回 PowerShell 5.1、不加载 `$PROFILE`、ZCode/Claude Code/CodeBuddy 等壳与配置差异、Git Bash 路径误伤、MCP 报错、代理继承、中文路径与 WSL2 边界」等关键缺口。依然做成**「人看得懂的道理 + 直接复制发给对方 AI 的升级交办单 + 小修小补胶水表」**。

## 一、先把 4 个最核心的问题用大白话讲透（给人看的）

### 1. 能把 Windows 自带的 PowerShell 5.1 直接删掉吗？
**千万别删，也删不掉。**
- 它不是普通软件，而是 Windows 核心系统文件（硬链接在 WinSxS 里，强删会被系统自动恢复回来，甚至搞坏系统更新）；更关键的是 **PowerShell 7 自己跑部分 Windows 管理功能时，后台也得拉起 5.1 跑兼容层**。
- **真正性价比最高、一劳永逸的做法不是“删 5.1”，而是“让 AI 默认先撞上 PowerShell 7”**：
  1. **用官方默认路径装 PowerShell 7**（必须在 `C:\Program Files\PowerShell\7\pwsh.exe`，**千万别换到 D 盘或绿色免安装版**！因为 Claude Code、Codex、Pi 的底层代码全都**写死了优先去找这个默认路径**，装在这它们 100% 优先用 7）。
  2. **把系统 `PATH` 里 `PowerShell\7` 排在前面**（给按名字找 `pwsh` 的工具铺路，并在 Windows Terminal 里把 5.1 菜单隐藏防手抖）。
  3. **把 UTF-8 写进用户环境变量而不止写 `$PROFILE`**（因为 AI 跑命令常带 `-NoProfile`，压根不读 `$PROFILE`）。

### 2. 日常用 PowerShell 7 够了吗？什么时候才需要上 WSL2（Linux 子系统）？
**普通人和 80% 日常开发：`Windows Terminal + PowerShell 7 + Git for Windows (Git Bash)` 完全够用，不用上 WSL2！**

| 你的情况 | 推荐底座 | 关键铁律 |
|---|---|---|
| **日常用 AI 办公、写网页/脚本、调用各种工具、电脑内存 ≤32G** | **Windows Terminal + PowerShell 7 + Git Bash** | 代码和文件放正常盘符即可；不要折腾 WSL2 吃内存和拖慢网络/桌面交互 |
| **重度后端开发、必须开系统级沙箱（Claude/Cursor 安全隔离）、跑纯 Linux 项目** | **WSL2（Ubuntu）** | **代码必须放 WSL 内部的 `~/projects/`，严禁放 `/mnt/c/...`**（跨盘小文件慢 456 倍，还会导致 AI 搜文件漏结果） |

### 3. 不同 AI 工具用的「壳」不一样怎么办？
| AI 工具 | 在 Windows 上怎么认壳 | 怎么稳住它不翻车 |
|---|---|---|
| **Claude Code** | 有 Git Bash 就默认走 **Git Bash**，没有才降级 PowerShell | **装好 Git for Windows**，配好 `CLAUDE_CODE_GIT_BASH_PATH`；它天生就会顺手跑 bash，少踩很多 PowerShell 坑 |
| **ZCode** | 官方设置只有 `Auto / CMD / Git Bash`（**没有 PowerShell 选项**，Auto 优先用 Git Bash） | 装好 **Git for Windows** 并在 ZCode 设置选 Git Bash 就稳了，别硬找 PowerShell |
| **Codex / Pi / Gemini CLI** | 优先找 `pwsh`（默认目录 `C:\Program Files\PowerShell\7\pwsh.exe`），找不到才落回 5.1 | 只要装在默认路径 + 配好全局规则提示词，基本不掉回 5.1 |
| **Cursor** | IDE 设置有时候管不住它的内置 Agent 终端 | 按官方文档把 `PowerShell` profile 指向 `pwsh.exe` 并将旧 `Windows PowerShell` 置 `null` |

### 4. Windows Terminal 怎样算「满血」（7 条基础手感 + 对标 Mac Ghostty 界面增强）
不用一上来就装容易乱码、拖慢启动的 `oh-my-posh` 和花哨主题，先调好下面这几条，手感与观感立刻追平 Mac：
1. **默认终端宿主**：打开 Windows Terminal「设置 → 启动」→ **默认终端应用程序选 `Windows Terminal`**，**默认配置文件选 `PowerShell 7`**（并把老旧的 `Windows PowerShell` 设为隐藏）。
2. **划选即复制、右键即粘贴**（体验提升最大）：开启 `"copyOnSelect": true`、`"copyFormatting": "none"`（只复制纯文本不带颜色），`"trimPaste": true`。
3. **Shift+Enter 换行不误发送**：PowerShell 7.3+ 自带 `Shift+Enter` 换行；为了兼容 cmd/WSL 等其他标签页，顺手加一条通用映射（`\u001b[13;2u`），注意在 Windows Terminal 里用 `Ctrl+Q` 等避开 `Alt+Enter` 全屏冲突。
4. **加大回滚历史方便搜日志**：`"historySize": 20000`（默认 9001），配合 `Ctrl+Shift+F` 全屏搜报错。
5. **自带神级分屏键 + 防误关**：`Alt+Shift++`（左右分屏）、`Alt+Shift+-`（上下分屏）、`Alt+方向键`（切窗口）、`Ctrl+Shift+W`（有分屏时只关当前分屏，没分屏才关标签页，跟 Ghostty 逻辑一致不误关）、`Ctrl+Tab`/`Ctrl+Shift+Tab` 切标签、`Ctrl+,`（秒开设置）。
6. **字体与轻度半透明**：`"face": "Cascadia Code"`, `"size": 12`, `"opacity": 80`, `"useAcrylic": true`。
7. **防中文路径/长路径雷区**：开系统长路径支持，且不要把用户临时目录和模型目录留在中文用户名下。

#### 重点补齐：参照 Mac Ghostty（GHO）的界面增强——尤其是「AI 粗体标橙黄」

用过 Mac Ghostty 的人都喜欢它在配置 `bold-color = #ffb86c` 后的效果：**AI 输出的中文重点粗体自动变成暖橙黄色，在黑底里一眼看清**（中文光加粗字重几乎看不出来）。以下是 Ghostty 常用增强在 Windows Terminal 里的逐项平替做法与真实边界：

| Mac Ghostty 增强项 | Windows Terminal 等价做法（微软官方字段） | 效果与诚实边界 |
|---|---|---|
| **`bold-color = #ffb86c`**（AI 粗体统一变橙黄） | **`"intenseTextStyle": "all"`** + 自定义配色方案（例如基于 `One Half Dark` 改一版 `AI Focus Dark`：保持 **`"foreground"` 与 `"white"` 色值完全一致**，只把 **`"brightWhite"` 改成 `"#FFB86C"`**） | **约 85% 平替**。WT 原生**没有**独立的 `boldColor` 字段，默认只提亮不加粗（`"bright"`）。但微软官方支持一条映射规则：当 `foreground` 与 `white` 完全相等且开 `"all"` 时，默认文字加粗（`\x1b[1m`）会自动既加粗又变成 `brightWhite`。<br>**边界**：① 极少数显式用亮白（`\x1b[97m`）输出的程序字也会一起变橙黄（若介意可改回 `#FFFFFF` 只留真加粗）；② 若某个 AI CLI 自己写死了 RGB 真彩色粗体，两端终端都不会覆盖它。 |
| **深色一体化观感 & 留白呼吸感** | 顶层加 **`"theme": "dark"`**；`defaults` 加 **`"padding": "10, 10, 10, 10"`**、**`"adjustIndistinguishableColors": "indexed"`** | 消除 Windows 浅色系统下「黑框终端配大白标题栏」的割裂感；四周留白不贴边；防止暗底上的深蓝/暗灰文字糊成一团看不清。 |
| **滚动条命令提示符标记（回看长对话）** | `defaults` 加 **`"autoMarkPrompts": true`**、**`"showMarksOnScrollbar": true`**（需 WT **1.21+**，低版本先跳过或先升级 WT） | 每次回车都在右侧滚动条自动打一个小刻度，配合 `Ctrl+↑/↓`（`scrollToMark`）在长输出里秒跳回上一轮提问。 |
| **切标签页 / 分屏防误关** | `Ctrl+Tab` / `Ctrl+Shift+Tab` 切标签；`Alt+Shift++`/`-` 分屏；`Ctrl+Shift+W`（`closePane`） | 分屏与防误关体验基本一致。 |
| **`cmd+\`` 窗口间直接轮换**（`goto_window`） | **无原生单键等价**，统一用系统 `Alt+Tab`，或全塞进同一个 WT 窗口多标签+分屏 | WT 官方 `actions` 没有“仅在多个 WT 窗口间轮换”的动作；推荐只开 1 个 WT 主窗口，用标签页区分项目、分屏并排跑 AI。 |

### 5. 主流 Windows 桌面端 AI 速查与防坑对照（好调 vs 调不了）

很多小白疑惑：**「我平时只用 Claude 桌面端、ZCode、CodeBuddy 或 Cursor，不用黑框终端，这套还能用吗？」**
**能用，而且约 75%～80% 底层全互通！** 上面讲的默认路径 `PowerShell 7` + `Git Bash`、用户级 `PYTHONUTF8=1`、MCP 排雷、不抢鼠标和挂机稳态，桌面端拉起子进程时**全都吃这一套**。只有 Windows Terminal 的界面美化与粗体标黄仅限黑框终端生效。

**一句话分清好调 vs 调不了**：
- **好调（底层互通）**：内置终端壳、UTF-8 编码、MCP 配置与排坑、全局规则注入、子进程代理继承。
- **调不了（劝退，别硬折腾）**：桌面端自己的界面字体与粗体标黄（封闭 Electron/WebView 渲染，改了更新也覆盖）；Electron 静默热更新自杀重启（过夜长任务仍建议丢终端 CLI 跑）；Windows 原生 OS 沙箱边界（除 Codex 外普遍缺原生沙箱）。

| 桌面端工具 | 内置壳怎么选 / 稳住 | MCP 配置路径与特有坑 | 全局规则放哪 | 调不了 / 特别注意 |
|---|---|---|---|---|
| **Claude 桌面端**<br>（Desktop / Code 标签页） | 官方明确 Windows 版**不读 `$PROFILE`**，环境变量须设系统/用户级再完全重启；Code 标签页有 Git Bash 就优先走 Git Bash | Desktop 聊天 MCP 在 `%APPDATA%\Claude\claude_desktop_config.json`；**微软商店（MSIX）版真配置藏在 `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\claude_desktop_config.json`**；Code 标签页读 `%USERPROFILE%\.claude.json` 与 Connectors | `%USERPROFILE%\.claude\CLAUDE.md` | 界面样式不可调；会后台静默热更新重启，不适合过夜挂机；原生 Windows 无沙箱 |
| **智谱 ZCode** | 设置 → 常规 → 终端只有 `自动选择 / CMD / Git Bash`（无 PowerShell）；装好 Git Bash 选它即稳 | 用户级 `%USERPROFILE%\.zcode\cli\config.json`（键 `mcp.servers`）；兼容兜底 `%USERPROFILE%\.agents\mcp.json`（**注意：只要 `.zcode` 下有任一 MCP，`.agents` 整份会被跳过**） | `%USERPROFILE%\.zcode\AGENTS.md`（不持续读 `CLAUDE.md`） | 设置 → 常规 → HTTP 代理**留空不等于跟随系统**（留空不读系统 `HTTP_PROXY`），须手动填好代理并重启；界面样式不可调 |
| **腾讯 CodeBuddy**<br>（IDE / 桌面端） | VS Code 底座：首选项设置里把默认集成终端设为 `PowerShell`（指向 `pwsh 7`）或 `Git Bash`；终端报错开 `Shell Integration: Decorations` | 对话右上角 Settings → MCP → `Add MCP`（或项目 `.mcp.json`）；**仅 `Craft` 模式可用 MCP（`Ask` 模式禁用）**，且配置名不能带空格；IDE 私有全局路径以软件内「Add MCP」打开为准（CLI 版在 `%USERPROFILE%\.codebuddy\mcp.json`） | 软件内设置 → 规则 → **User Rules**（项目级支持 `.codebuddy/rules/` 或 `CODEBUDDY.md` / `AGENTS.md`） | 代理设置看 IDE 内 `http.proxy` / `codingcopilot.httpProxyURL`；界面样式固定 |
| **Cursor** | VS Code 底座：设置里把 `PowerShell` profile 指向 `pwsh.exe`，旧 `Windows PowerShell` 置 `null` | 全局 `%USERPROFILE%\.cursor\mcp.json`、项目 `.cursor\mcp.json`；避开裸 `npx` 与单反斜杠 | Customize → Rules → **User Rules**（软件内界面编辑最稳；项目级 `.cursor\rules\*.mdc` 或 `AGENTS.md`） | 界面样式固定；原生 Windows 无沙箱（沙箱需走 WSL2） |
| **Codex 桌面端**<br>（ChatGPT Windows App） | 默认原生 PowerShell；可在设置独立选内置终端壳（PowerShell / CMD / Git Bash / WSL）及切换 Agent 运行环境 | 与 Codex CLI 共用 `%USERPROFILE%\.codex\`（配置 `config.toml`）；若切到 WSL2 运行需重启并在 WSL 设 `CODEX_HOME` 共享 | `%USERPROFILE%\.codex\AGENTS.md` | 唯一支持原生 Windows 沙箱（MXC 等）；界面样式不可调，切环境后需彻底重启 |

> **高频隐藏坑 · 桌面端网络代理继承**：很多人在桌面端聊天一切正常（软件自带浏览器壳走了系统代理），但一让它跑终端装包或连本地 MCP 就报超时 / `ECONNREFUSED`。排查两条：① 看软件内单独的代理开关（例如 **ZCode 留空不会读系统 `HTTP_PROXY`**，**CodeBuddy 要核对 `http.proxy` / `codingcopilot.httpProxyURL`**）；② 看用户级环境变量 `HTTP_PROXY` / `HTTPS_PROXY` 是否与代理端口一致，改完后必须**彻底退出桌面端（含托盘图标）再重开**。

## 二、核心交付物：直接复制发给你的 AI 的升级版交办提示词

把下面这段话直接发给你这台 Windows 电脑上的 AI（升级合并自 Windows PowerShell 防坑规则与最新实证补丁）：

````markdown
请你帮我把这台 Windows 电脑的「终端、命令行、编码、MCP 环境」一次性调到满血、不打架、不乱码的状态。记住：每改已有文件前先备份，需要管理员权限或改系统设置时先暂停告诉我再执行。

【第 1 步：体检与安装基础壳（别删 5.1，装默认路径的 pwsh 7 + Git Bash）】
1. **绝对不要删除系统自带的 PowerShell 5.1**（系统组件与兼容层依赖它）。
2. 检查 PowerShell 7 是否已装在默认路径 `C:\Program Files\PowerShell\7\pwsh.exe`：
   - 没有或版本低于 7.4：征得我同意后运行：
     `winget install --id Microsoft.PowerShell --source winget --accept-source-agreements --accept-package-agreements`
   - 确保系统 `PATH` 中 `C:\Program Files\PowerShell\7` 排在系统自带 `WindowsPowerShell\v1.0` 之前（改动系统变量前先备份原 PATH）。
3. 检查是否已装 Git for Windows（`C:\Program Files\Git\bin\bash.exe`）：
   - Claude Code、ZCode 等工具重度依赖 Git Bash；如缺失，征得我同意后用 `winget install --id Git.Git --source winget` 安装。
   - 若本机主要用 Claude Code，检查并配置用户级环境变量 `CLAUDE_CODE_GIT_BASH_PATH=C:\Program Files\Git\bin\bash.exe`。

【第 2 步：把 Windows Terminal 调到满血（含参照 Ghostty 的界面增强与粗体标黄）】
> **前置分流**：如果用户已明确平时**只用桌面端**（Claude 桌面端 / ZCode / CodeBuddy / Cursor / Codex 等）、几乎不开黑框终端，**直接跳过本第 2 步**进入第 3 步；若用终端或两者都用，则完整执行。
1. 检查是否安装了官方 **Windows Terminal**（没有则提示我从微软商店或 winget 安装 `Microsoft.WindowsTerminal`，顺便确认版本号是否 ≥ 1.21）。
2. 找到 Windows Terminal 的 `settings.json`（先备份原文件），帮我**安全合并**以下设置（不要覆盖我原本的其他自定义项）：
   - **顶层**：加 `"theme": "dark"`, `"copyOnSelect": true`, `"copyFormatting": "none"`, `"trimPaste": true`
   - **在 `schemes` 数组里安全追加一套配色 `"AI Focus Dark"`**（同名已存在则先确认再替换，不动其他已有方案）：
     `{ "name": "AI Focus Dark", "background": "#282C34", "foreground": "#DCDFE4", "cursorColor": "#FFFFFF", "selectionBackground": "#474E5D", "black": "#282C34", "red": "#E06C75", "green": "#98C379", "yellow": "#E5C07B", "blue": "#61AFEF", "purple": "#C678DD", "cyan": "#56B6C2", "white": "#DCDFE4", "brightBlack": "#5A6374", "brightRed": "#E06C75", "brightGreen": "#98C379", "brightYellow": "#E5C07B", "brightBlue": "#61AFEF", "brightPurple": "#C678DD", "brightCyan": "#56B6C2", "brightWhite": "#FFB86C" }`
     （原理：保持 `foreground` 与 `white` 严格同色，配合 `"intenseTextStyle": "all"`，即可把默认加粗输出标成 Ghostty 同款橙黄 `#FFB86C`；并提前告诉我如果以后某些程序的亮白字也变黄不习惯，可把 `brightWhite` 改回 `#FFFFFF`。）
   - **在 `profiles.defaults` 加**：`"colorScheme": "AI Focus Dark"`, `"intenseTextStyle": "all"`, `"adjustIndistinguishableColors": "indexed"`, `"padding": "10, 10, 10, 10"`, `"historySize": 20000`, `"opacity": 80`, `"useAcrylic": true`, `"font": { "face": "Cascadia Code", "size": 12 }`；若本机 WT 版本 ≥ 1.21，再加 `"autoMarkPrompts": true`, `"showMarksOnScrollbar": true`（低于 1.21 则跳过这两条以免报错）。同时检查 `profiles.list` 里的 PowerShell 7 / Git Bash 条目，如果它们单独写死了旧的 `"colorScheme"`，征得我同意后移除或改为 `"AI Focus Dark"`，以免盖掉 `defaults`。
   - **隐藏老壳并定默认**：找到 `Windows PowerShell`（5.1）那条 profile，设 `"hidden": true` 防手抖；把 `defaultProfile` 指向 PowerShell 7 的 GUID。
   - **在 `actions`（或新版 WT 的快捷键列表）里安全追加**（先检查是否已绑定同键位避免冲突）：
     - `shift+enter` 换行兼容序列：`{ "command": { "action": "sendInput", "input": "\u001b[13;2u" }, "keys": "shift+enter" }`
````

## 三、出问题自己粘胶水：常见小毛病速查表

| 遇到的毛病 | 真实原因 | 粘胶水修法 |
|---|---|---|
| **明明在 Windows Terminal 开了 pwsh 7，AI 跑起来还是用 5.1** | `C:\Windows\System32\WindowsPowerShell\v1.0` 在系统 PATH 前面，或工具写死路径找不到 | 检查 `pwsh.exe` 是否装在默认 `C:\Program Files\PowerShell\7\`；把该路径挪到**系统 PATH** 最前并重启电脑 |
| **终端里打字不乱码，AI 自己跑脚本就乱码** | AI 调子进程带 `-NoProfile`，压根没读 `$PROFILE` | 配好用户环境变量 `PYTHONUTF8=1`；复杂中文文本交给 Python 脚本处理；若写了 `.ps1` 给 5.1 跑，文件必须存成 **UTF-8 带 BOM** |
| **ZCode / Claude Code 选不了 PowerShell 或一选就错** | ZCode 天生只认 CMD/Git Bash；Claude Code 只要有 Git Bash 就默认走它 | 装好 **Git for Windows**，让它们安心走 Git Bash，同时给它们配上 Git Bash 防斜杠乱转义规则即可 |
| **配好 MCP 报错 `spawn npx ENOENT` 或 `EINVAL`** | Windows 上 `npx` 是 `.cmd` 批处理，新版 Node 不允许直接裸调 | 改成指向真实的 `node.exe` 绝对路径 + 入口 `.js`；或先试 `cmd /c npx`（如遇杀软拦截 `EPERM` 则改回直连 `node.exe`） |
| **改了 Claude Desktop 的 MCP 配置却完全不生效** | 装了微软商店（MSIX）版，真配置被虚拟化藏在 `LocalCache` 里 | 让 AI 顺便检查 `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\claude_desktop_config.json` |
| **Git Bash 传 `/xxx` 参数给工具时莫名变成 `C:/Program Files/Git/xxx`** | MSYS2 自动把 `/` 开头参数当 Unix 路径转换了 | 只给那条命令临时加环境变量：`MSYS_NO_PATHCONV=1 <你的命令>` |
| **改了 `settings.json` 后一打开 WT 就弹窗报错，或配色完全没变** | 多写/少写了逗号、`profiles.list` 里单个配置自己写死了 `colorScheme` 盖掉了 `defaults`，或用了含 `//` 注释导致解析器挑刺 | 让 AI 跑 `Get-Content <settings.json> -Raw \| ConvertFrom-Json` 查出语法错行；并检查 `profiles.list` 对应项里有没有单独的 `"colorScheme"` 覆盖了全局默认 |
| **已经设了 `brightWhite: "#FFB86C"`，AI 粗体还是普通白字不变黄** | `intenseTextStyle` 没设为 `"all"`（默认是 `"bright"`），或者当前配色的 `foreground` 和 `white` 色值不相等 | 核对 `profiles.defaults` 里有 `"intenseTextStyle": "all"`，且当前 `colorScheme` 的 `"foreground"` 与 `"white"` **必须完全一模一样**（如都是 `"#DCDFE4"`）；若某 AI CLI 自己写死 RGB 颜色则属正常边界 |
| **打开 WT 提示 `autoMarkPrompts` / `showMarksOnScrollbar` 未知设置** | 本机 Windows Terminal 版本低于 1.21（旧版带 `experimental.` 前缀） | 运行 `winget upgrade Microsoft.WindowsTerminal` 升到最新版，或暂时从 `settings.json` 删掉这两行即可 |
| **用 WSL2 跑 AI 搜代码超慢、甚至经常搜漏文件** | 仓库放在 Windows 的 `/mnt/c` 里，跨虚拟机边界掉速 456 倍 | 把常用仓库 `git clone` 到 WSL 内部的 `~/projects/` 目录下，Windows 编辑器通过 Remote-WSL 打开 |
| **桌面端聊天正常，但内置终端或 MCP 装包/联网超时** | 桌面端内部代理与系统环境变量不同步（如 ZCode 留空不读系统 `HTTP_PROXY`），或改了环境变量未彻底重启应用 | 核对桌面端软件内代理设置（ZCode 填好 HTTP 代理；CodeBuddy 查 `http.proxy`），同步用户级 `HTTP_PROXY`/`HTTPS_PROXY` 后**彻底退出托盘图标再重开** |
